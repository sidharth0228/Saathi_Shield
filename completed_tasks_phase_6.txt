========================================================================
SAATHI SHIELD - COMPLETED DEVELOPMENT SUMMARY (PHASES 6 & 9 NOTIFICATIONS)
========================================================================

Below is the summary of the emergency Notification Center, global overlay
banners, push notification logic, and developer simulation controls built for
Phases 6 and 9 of the Saathi Shield mobile application.

------------------------------------------------------------------------
1. EMERGENCY NOTIFICATION CENTER & LOCAL PERSISTENCE
------------------------------------------------------------------------
- Notification Model (mobile/lib/models/notification_model.dart)
  * Defines notification category, timestamps, read/unread states, and payloads.
- Local Storage helper (mobile/lib/services/local_storage_service.dart)
  * Added JSON serialize/deserialize caches to persist notification history.
- Notification Provider (mobile/lib/providers/notifications_provider.dart)
  * riverpod state notifier managing the unread lists and notification CRUD.
  * unreadNotificationsCountProvider tracks badge count reactively.
- Notification Center Screen (mobile/lib/features/notifications/)
  * Chronological timeline view with vertical flow connecting dots.
  * Category chips filter list by SOS, Travel, Community, and Disaster alerts.
  * AppBar actions to Read All, and footer action to Clear All.
  * Redirects on tap to destination screen (e.g. live tracking, disaster view).

------------------------------------------------------------------------
2. GLOBAL IN-APP ALERTS FLOATING BANNERS
------------------------------------------------------------------------
- Active Banner Provider (mobile/lib/providers/active_banner_provider.dart)
  * Riverpod state controller for the active banner, with 5s auto-dismiss timers.
- Global Alert Banner (mobile/lib/widgets/global_alert_banner.dart)
  * Slide-down warning cards colored by type (crimson SOS, orange travel warnings,
    green volunteer alerts, purple disaster warnings).
  * Manual close options and click redirects matching push notification payloads.
- Global Stack Integration (mobile/lib/main.dart)
  * Positioned banner overlay globally above child navigators using MaterialApp's
    root builder parameter, ensuring alerts show over any active screen.

------------------------------------------------------------------------
3. DISASTER PROTOCOLS & WARNING FEEDS
------------------------------------------------------------------------
- Disaster Alerts Screen (mobile/lib/features/safety/disaster_alerts_screen.dart)
  * Lists active regional alerts, warning regions, and danger zones.
  * Details critical safety protocols (Go-bag setups, storm precautions).

------------------------------------------------------------------------
4. DEVELOPER SIMULATION CONTROLLER (DEMO MODE)
------------------------------------------------------------------------
- Mock Dispatch Controller (mobile/lib/features/demo/demo_controller_screen.dart)
  * Dev-only simulation triggers:
    1. Simulate SOS: Triggers panic state directly, overlaying dashboard, showing 
       stopwatch timers, and sliding down emergency banners.
    2. Simulate Travel Anomaly: Starts travel session, forces path coordinates off
       route, and flags GPS warning alerts.
    3. Simulate Volunteer Accept: Feeds volunteer accepted events (ACCEPTED -> 
       EN_ROUTE -> ARRIVED) to sosTrackingProvider to animate volunteer movements
       towards the victim in real-time.
    4. Simulate Disaster: Dispatches weather storm warnings and links to protocols.
- Route & Drawer Integrations
  * Registered app routes in router and added Drawer listings and AppBar badge 
    counters on DashboardScreen.
========================================================================
